# TivalVideo Offline 0.3.0

## New narrator system

- Choose a narrator with the Python `voice=` argument or CLI `--voice` option
- Four bundled voice definitions: Lessac, Amy, Joe, and Alan
- Download voices individually for offline use
- List installed voices with `tivalvideo voices list`
- Install with `tivalvideo voices install VOICE`
- Remove unused models with `tivalvideo voices remove VOICE`
- Existing programs continue using `en_US-lessac-medium` by default
